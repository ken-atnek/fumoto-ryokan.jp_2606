# レビュー指摘トラッカー

Claudeなど外部レビューで出た指摘を管理するためのメモです。
指摘はすべて採用する前提にせず、優先度・影響範囲・既存方針との相性を確認してから反映します。

---

## ステータス定義

- `未着手`
- `対応中`
- `対応済み`
- `保留`
- `対応不要`

## 次回レビュー時チェック

- PC / SP の両方で違和感がないか
