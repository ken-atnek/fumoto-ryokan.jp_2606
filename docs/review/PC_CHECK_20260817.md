## 2. 気になる点（優先度別）

### 優先度：高

1. **全下層ページのcanonical・OGPがトップページと同一になっている（SEO）**
   本番ビルド（`NEXT_PUBLIC_IS_REAL_PROD=true`）で確認したところ、`/access/` `/rooms/` `/onsen/` `/news/` など全ページで
   `<link rel="canonical" href="https://www.fumotoryokan.com/">` と、OGPの `og:title` `og:description` `og:url` がすべてトップページの内容のまま出力されていました。
   `alternates.canonical` と `openGraph` / `twitter` が `src/app/layout.tsx` にしか定義されておらず、各 `page.tsx` 側で上書きされていないことが原因です。
   このままだと検索エンジンが下層ページを「トップページの重複」と判断しかねず、SNSでどのページを共有してもトップページのカードが表示されてしまいます。

2. **温泉ページ：「石くり抜き風呂」と「岩組み露天風呂」の説明文が完全に同一（コンテンツ誤り）**
   `src/components/onsen/onsenContentData.ts` の `id: 'ishikurinuki'` と `id: 'iwakumi'` の `body` が一言一句同じ文章（「石くりぬき風呂の隣にあるのがこの岩組みの露天風呂です…」）になっています。本来「石くり抜き風呂」自体の説明文が必要です。
   また `id: 'ashiyu'`（足湯）の画像が `/images/top/bathroom11.webp`（トップページ用の汎用写真）になっており、`alt` も「別館 家族露天 岩組み露天風呂」のままコピペが残っています。足湯専用の写真とalt文言への差し替えが必要です。

3. **過ごし方ページ：チェックアウト時刻の表記ミス**
   `src/components/stay/stayContentData.ts` の `checkout.body` が「**10:10:00**チェックアウトとなります。」となっています（隣のアイコン表記は正しく「〜10:00」）。予約・滞在に直結する情報のため優先して修正をお願いします。

### 優先度：中

4. **お知らせ一覧・詳細ページだけ他ページと作りが異なる**
   `src/app/news/page.tsx` と `news/2026-05-10-renewal/page.tsx` は `module.scss` を使わずインラインstyleで組まれており、他ページにあるヒーロータイトル（大きな縦書きの見出し）やヘッダー背景などのデザインが適用されていません。`docs/rules/coding-style.md` の「スタイルはSCSSで実装する」方針とも異なるため、本実装のタイミングでデザインを揃えることをおすすめします。

5. **sitemap.xmlに `/news/` 系のURLが含まれていない**
   `src/app/sitemap.ts` はURLを配列に直書きしており、`/news/` と `/news/2026-05-10-renewal/` が漏れています。お知らせは今後増える想定のため、記事一覧から動的に生成する形にしておくと漏れ防止になります。

6. **過ごし方ページの「かじかショップ」「SLOW WORK CAFE」が空のグレー枠のまま**
   `placeholder: true` の箇所は画像なしのグレーボックス表示になっています。`docs/PAGE_STRUCTURE.md` 等では「写真素材未確定の箇所は既存画像で仮置き」とありますが、現状は完全な空枠なので、意図した状態か（差し込み予定か）確認をお願いします。

7. **下層ページ本文中に予約CTAが少ない**
   お部屋・お料理・温泉などのページは、ヘッダー／フッターの「ご予約はこちら」以外に本文中の予約導線がありません。魅力を伝えた直後（各ページの末尾など）に予約ボタンを置くと、AGENTS.mdにある「予約導線が自然か」という観点でより効果的だと思います。

### 優先度：低

8. **過ごし方ページの時計アイコンと実際の時刻の不一致**
   用意されている時計アイコンが5種類（15/17/18/19/22時）しかなく、「5:00〜」「6:00〜」に同じ`clock17.webp`が使われる、「〜10:00」に`clock22.webp`が使われるなど、時刻とアイコンが噛み合っていない箇所が複数あります。装飾要素なので優先度は低いですが、追加のアイコン用意を検討してください。

9. （参考）トップページ「アクセス」内のGoogleマップ埋め込みは本チェック環境のネットワーク制限で表示確認できませんでした。実機での表示確認をお願いします。

## 3. Codexで修正する場合のおすすめ順

1. `src/app/layout.tsx` の `alternates.canonical` / `openGraph` を各 `page.tsx` 側で自ページのURL・タイトル・説明文に上書きするよう修正（SEO影響が最も大きいため最優先）
2. `src/components/onsen/onsenContentData.ts` の「石くり抜き風呂」説明文の書き直しと、「足湯」の画像・alt差し替え
3. `src/components/stay/stayContentData.ts` のチェックアウト文言「10:10:00」→「10:00」修正
4. `src/app/sitemap.ts` に `/news/` 系URLを追加（可能であれば記事データからの動的生成に変更）
5. `src/app/news/` 配下のページを他ページと同じデザイントーン（SCSS・ヒーロータイトル）に合わせて作り直し
6. 過ごし方ページのプレースホルダー画像の扱いを確認・差し込み、下層ページへの予約CTA追加を検討
