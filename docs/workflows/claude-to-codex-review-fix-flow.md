# Claudeレビュー反映依頼フロー

Claudeのレビュー結果をCodexに渡し、採用可否と修正方針を整理するための手順です。  
Claudeの指摘はそのまま実装せず、Codex側で既存ルールと照らし合わせて判断します。

---

## 目的

- Claudeのレビュー結果を実装可能な粒度に整理する
- 採用 / 保留 / 対応不要を明確にする
- 修正対象ファイルと影響範囲を先に確認する
- 大きすぎる変更を避け、最小修正で反映する

---

## 手順

1. Claudeのレビュー結果をコピーする
2. 対象ページ、URL、関連ファイルを整理する
3. 下記の「Codexへ渡すプロンプト」を使ってCodexへ依頼する
4. Codexに採用可否・理由・対象ファイル・修正方針を整理させる
5. 必要な指摘を `docs/review/REVIEW_FIX_TRACKER.md` に転記する
6. 高優先度かつ影響範囲が小さいものから対応する
7. 実装前に修正範囲を確認する
8. 修正後にPC / SP表示、予約導線、SEO上の影響を確認する
9. 対応結果を `docs/review/REVIEW_FIX_TRACKER.md` に記録する

## 判断基準

### 採用

- 予約導線がわかりやすくなる
- 旅館の魅力が伝わりやすくなる
- 情報の優先順位が整理される
- SEOやアクセシビリティ上の明確な改善になる
- 既存構成に自然に組み込める

### 保留

- 効果はありそうだが、影響範囲が大きい
- 写真素材や原稿が未確定で判断しにくい
- 他ページとの整合性を見てから決めたい
- デザイン全体への影響が大きい

### 対応不要

- 既存方針と合わない
- 作り直し前提になっている
- 実装コストに対して効果が小さい
- 旅館サイトの目的から外れている
- すでに別の形で対応済み
