# 失敗と対策メモ

作業中に起きた失敗や迷いを、次回以降の対策として残すためのメモです。  
新しい失敗が出たら、1行ずつ追記します。

---

## 記録ルール

- 「失敗」と「対策」をセットで書く
- 個人の反省ではなく、次回の作業ルールとして残す
- 内容が増えすぎたら、重要度の高いものだけ残す

---

## メモ

| 失敗 | 対策 |
|---|---|
| 指摘を全部採用して構成が崩れた | 採用前に優先度と影響範囲を確認する |
| AIにコードまで出させて既存ルールとズレた | Claudeにはレビューのみ依頼し、実装はCodexで行う |
| 長文依頼でチェック観点がぼやけた | 1回のレビュー依頼では対象ページと観点を絞る |
